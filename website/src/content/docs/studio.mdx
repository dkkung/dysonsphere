Upload CSV, TSV, or JSON data. Choose a chart, add statistics, multilabel tables, and annotations, and tune the theme. The builder reads uploaded data in the browser, where Pyodide runs the chart code.

Select **Edit as code** to open the generated Python in a live editor. The editor uses the same runtime and keeps the uploaded file available under its original filename. Guide examples link to this editor with *Open in studio*.

Import a figure saved by `ds.save()`: a Vega-Lite JSON export rebuilds the chart through `ds.load()`. JSON, SVG, and PNG exports display their embedded provenance, statistics, and report metadata from `ds.metadata.read()`.

The chart appears after the Python runtime loads. The first load can take a few seconds; the runtime is cached afterward. The default dataset is cars. Upload another file or choose a sample dataset.

<Studio />

:::note
The copied Python runs unchanged in your notebook – it reads your file with `pl.read_csv(...)`,
computes statistics with scipy, and draws everything through Altair. See the
[comparisons guide](/guides/comparisons/) for what the tests report, and
[saving & reading](/guides/saving/) for exporting figures with embedded provenance.
:::
