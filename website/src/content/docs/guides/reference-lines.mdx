`ds.rule()` returns a native Altair layer. Add it to a chart with `+`; the rule shares the chart's
scales. Use `y=...` for a horizontal rule or `x=...` for a vertical one. Both can have labels.

`strokeDash` controls the line pattern:

- `None` inherits the theme's `ruleStrokeDash` setting.
- `True` uses the theme's shared `strokeDash` pattern.
- `False` forces a solid rule.

## Limit a rule to a span

`span=(start, end)` limits a horizontal or vertical rule to part of the axis it runs along. Bounds
can be numeric data coordinates or category names. Category names are resolved through the band
scale and require `categories`, as in `ds.shade`. A label anchors to the span's ends:

<Example name="rule_span" alt="Bar chart of mean MPG by cylinder count with a benchmark line sliced across the six- and eight-cylinder bars" />

## Explicit endpoints

Use endpoint coordinates to draw bounded horizontal or vertical rules, or a diagonal segment:

- `ds.rule(x=2, x2=8, y=5)` draws a bounded horizontal rule.
- `ds.rule(x=5, y=2, y2=8)` draws a bounded vertical rule.
- `ds.rule(x=2, y=3, x2=8, y2=9)` draws a diagonal segment.

Diagonal labels remain horizontal. `labelAlign` selects the smaller-x endpoint, data-coordinate
midpoint, or larger-x endpoint; `labelPosition` places the text above or below it. These anchors do
not account for reversed or nonlinear scales.

## Equation mode

Equation mode draws a segment over a required numeric x extent. For example,
`ds.rule(slope=2, intercept=1, span=(0, 5))` draws `y = slope*x + intercept` across that extent.
The equation is represented accurately only on linear quantitative x and y scales. For nonlinear
scales, calculate suitable visual coordinates and use explicit endpoints.

## Caps and gaps

`startCap` and `endCap` add `"arrow"`, `"circle"`, or `"square"` endpoint decorations. When a cap
is present, `startGap` and `endGap` default to a clearance based on the theme's marker size, marker
stroke, and rule width. Without a cap, the default gap is 0. Explicit gaps also shorten capless
rules.

The start and end follow explicit endpoint or span order, regardless of scale direction. For a full
rule without explicit endpoints, start and end are the left and right edges for horizontal rules,
and the top and bottom edges for vertical rules:

```python
decorated = targets + ds.rule(
    x=2, y=3, x2=8, y2=8,
    startCap="arrow", endCap="arrow",
)
ds.save(decorated, "decorated", format=["svg", "png"])
```

Caps and gaps are corrected from rendered SVG geometry in `ds.save()` SVG/PNG and `ds.show()`,
so they follow facets, reversed scales, and chart aspect ratio. Bare Altair display and interactive
HTML show the rule without caps or gaps.
