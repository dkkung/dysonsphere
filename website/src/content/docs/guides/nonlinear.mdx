The log- and power-axis helpers add minor ticks. The dysonsphere theme disables Vega's integer tick
rounding, so minor tick positions remain exact at render time in any renderer.

## Log axes

`add_log_ticks()` adds unlabeled minor ticks to a log-scale axis (base 10 or any integer base). It
wraps the chart in a layer with a separate minor-tick axis and leaves the main chart's scale domain
unchanged.

<Example name="log" alt="Log-scale line chart of stock prices with minor ticks" />

## Power axes

`add_pow_ticks()` adds minor ticks to power and square-root scales, evenly spaced in transformed
space. Pass the same `majorValues` as on the main axis. When ticking both axes, pass each axis's
major tick values.

<Example name="nonlinear_pow" alt="Square-root axis scatter with evenly spaced minor ticks" />

## Typeset labels

`log_label_expr()` returns a Vega `labelExpr` for superscript log labels (`10¹`, `10²`, …), in
`"power"`, `"scientific"`, `"e"`, or `"si"` notation.

<Example name="nonlinear_labels" alt="Log-scale chart with typeset power-notation labels" />

These exponents are typeset by the same mechanism that handles superscripts and subscripts in any
label - so you can also write `x^2` or `C__t` in an axis title or annotation. See
[Superscripts and subscripts](/guides/text-labels/#superscripts-and-subscripts).
