dysonsphere's composite marks return native Altair layers that you can combine with `+` and other
Altair chart methods. Their jitter, beeswarm, and quasirandom offsets are also available as
standalone [transforms](/guides/transforms/).

For strip and violin marks, `categories` sets display order and must contain each observed group
exactly once. Filter the dataframe first when plotting a subset of groups.

## Strip plot

`mark_strip()` draws a categorical scatter with a summary. By default, the summary is the group
mean with SEM error bars; `errorbars=False` selects the median instead. Points are jittered by
default.

## Violin plot

`mark_violin()` pairs an outlined kernel-density silhouette with Prism-style inner statistics -
a solid median line and dashed quartile lines, each spanning the violin's width at that value.
`inner=` picks the display: `"quartiles"` (default), `"median"` (median line only), `"box"` (an
embedded boxplot), or `None` (silhouette only); `innerColor` restyles the lines:

<Example name="violin" alt="Violin plot of horsepower by car origin" />

Remove the outline with `stroke=None`, and trim the violin tails at the observed data extremes
with `trim=True`; `bandwidth` controls KDE smoothness:

### Palettes and fixed fills

`mark_strip()` and `mark_violin()` both return an `alt.LayerChart`. Use `palette=` for category
colors: it accepts a registered palette name (including a loaded custom palette) or a nonempty
list of colors. A name uses the full registered list; it is not resampled. With `palette=None`,
colors inherit the theme's category range.

Use `fill=` for one literal color instead:

```python
palette_strip = ds.mark_strip(data, "group", "value", categories, palette=["#4C78A8", "#F58518"])
fixed_violin = ds.mark_violin(data, "group", "value", categories, fill="#888888", legend=True)
```

`palette` and `fill` cannot both be non-`None`; inheriting the theme palette is not a conflict.
With a fixed fill, only the category-color legend is hidden, even when `legend=True`. Axes, other
legends, summaries, and violin inner styles remain. The literal fill stays the same in light and
dark mode.

## Boxplot

Plain Altair marks also inherit the theme. `mark_boxplot()` uses grey boxes, a single-stroke median,
and rounded whisker caps. Outlier points are hidden by default. Use Altair's native
`mark_boxplot(outliers={"size": 5})` override to show or style them per chart.

## Table

`mark_table()` renders a DataFrame as a composable Altair table layer. Columns are formatted per
column using the library's scientific, power, and SI notations, with superscripts typeset in the
output. A numeric column can be shaded by value with
`cellPalette`; and `strokes` picks which rules to draw (`"outer"`, `"header"`, `"rows"`, `"cols"`,
`"grid"` for the interior, or `"all"` for every rule). Numeric columns are right-aligned by default
so figures line up on the decimal; everything else is left. The source DataFrame is never mutated, so
`ds.metadata.read(what="data")` recovers the inlined data. Each cell background is a separate rect,
so you can recolor individual cells in Illustrator.

Missing or non-finite values serialize as `null` and render as blank cells without dropping rows;
zero remains `0`. Named numeric notations reject non-missing strings, while explicit d3 formats
use Vega's formatter and may format strings (including padded `c` values). Booleans accept numeric
formats, and all-missing columns stay blank. Widths are estimates, not a second Python formatter;
use `columnWidths=` for exact control. Formatting maps validate known input columns, while
`headerLabels` remains a permissive display map.
