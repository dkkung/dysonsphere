`add_multilabel()` adds an annotation table below a chart with `+`/`-` rows, symbols, or text
aligned to x categories. The table can also include sample-size and category-label rows and grouped
spans.

`order=` may select a subset of rows, but listed labels must be known and unique. `rowStyles=`,
`rowHeight=`, and `rowValueAngle=` mappings validate keys against all supplied groups, including
groups omitted from `order`.

<Example name="multilabel" alt="Strip plot with a plus/minus multilabel table below" />

`showSampleSize=True` injects a per-category count row, and `categoryLabel=True` renders the
category names as an angled row of the table:

<Example name="multilabel_sample_size" alt="Strip plot with sample size and category-label rows" />

Use `style="symbol"` for filled and open dots, and `span=` to bracket groups of categories under
a shared label:

<Example name="multilabel_symbol" alt="Strip plot with a symbol multilabel table and grouped spans" />

## Rotating row values

A row of numbers, such as doses, timepoints, or concentrations, may exceed its band's width. Set
`rowValueAngle` in degrees to rotate the values: `-90` reads bottom-to-top, and `90` reads
top-to-bottom. Values rotate about their center, so they stay centered on their category. The row
grows to fit its tallest rotated value.

Provide a **list** of angles, one per category, to rotate selected cells. In the example, the
untreated controls' `-` placeholders remain upright while the dose values rotate:

<Example name="multilabel_rotated" alt="Dose response strip plot with the dose row standing on end" />

All four shapes:

```python
rowValueAngle=-90                              # every row
rowValueAngle={"Dose (µM)": -90}               # one row, by label
rowValueAngle=[0, -90]                         # one per row, in display order
rowValueAngle={"Dose (µM)": [0, 0, -90, -90]}  # one per cell of that row
```

Rotation applies to all row styles. In a `"symbol"` row, it rotates the marks as well as the
characters in text rows. The default `"circle"` looks the same at any angle, so use an oriented
shape such as `symbol="triangle-up"` to see the rotation.

Rows are 10 px tall by default, and rotated rows auto-size. Set explicit heights with `rowHeight`,
which accepts a single height, a dict keyed by row label, or a list in row-display order:

```python
rowHeight=14                          # every row
rowHeight={"Dose (µM)": 26}           # one row; the rest auto-size
```

:::note
A lone `-` in a text row renders as a typographic minus (`−`), matching what a `plusminus` row
draws for `False`, so placeholder rows line up with `+`/`−` rows above them.
:::
