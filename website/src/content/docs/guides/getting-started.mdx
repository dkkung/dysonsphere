## Install

```sh
# with pip
pip install dysonsphere

# with uv
uv pip install dysonsphere

# add as a project dependency
uv add dysonsphere
```

Requires Python >= 3.11. The runtime dependencies install with it:

- [Altair](https://altair-viz.github.io/) >= 6.0 - the charting layer
- [Polars](https://pola.rs/) >= 1.19 - the native `DataFrame` ([pandas](https://pandas.pydata.org/) input is accepted and converted)
- [NumPy](https://numpy.org/) >= 1.26 - numeric primitives
- [SciPy](https://scipy.org/) >= 1.11 - the statistics behind `ds.stats.comparisons()` / `ds.stats.correlation()`
- [vl-convert](https://github.com/vega/vl-convert) >= 1.9 - the SVG/PNG renderer behind `save()`

`pandas` and `duckdb` are optional - only needed for `read(..., output="pandas"/"duckdb")`.

dysonsphere adds themes, marks, annotations, and export helpers to [Altair](https://altair-viz.github.io/). Its chart functions return Altair chart objects, and data can be a [polars](https://pola.rs) or [pandas](https://pandas.pydata.org/) `DataFrame`.

## The shape of the library

Import the library through one namespace, conventionally named `ds`:

- **`ds.theme()`** - register a global theme. Charts built afterwards inherit its palettes and
  styling. See [Theming](/guides/theming/).
- **Marks** - `ds.mark_strip()`, `ds.mark_violin()` build composite plots. See [Marks](/guides/marks/).
- **Annotations** - `ds.rule()`, `ds.text()`, `ds.shade()`, `ds.labels()` return
  layers you add with `+`. See [Reference lines](/guides/reference-lines/),
  [Shading](/guides/shading/), and [Text & labels](/guides/text-labels/).
- **Statistics** - `ds.stats.comparisons()` and `ds.stats.correlation()` draw significance tests and
  fits that carry a report into the export. See [Comparisons](/guides/comparisons/) and
  [Correlation](/guides/correlation/).
- **`ds.save()`** - write figures and their metadata. **`ds.metadata.read()`** reads metadata and, for JSON exports, captured data. **`ds.load()`** rebuilds a chart from a JSON export. See [Saving & reading](/guides/saving/).

`ds.theme()` registers the theme; `palette="blues"` sets the categorical color scheme. Because the
theme is global, plain `alt.Chart(...)` picks it up - dysonsphere only had to set the palette.

## Saving

```python
ds.save(chart, "figure")   # writes figure.svg + figure.json by default
```

`save()` writes provenance, the resolved theme, and any statistics to the export. `ds.metadata.read()` reads metadata from JSON, SVG, or PNG; captured data is available only from JSON. `ds.load()` rebuilds a chart only from JSON.
