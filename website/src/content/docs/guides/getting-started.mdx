## Install

```sh
# with pip
pip install dysonsphere

# with uv
uv pip install dysonsphere

# add as a project dependency
uv add dysonsphere
```

Requires Python >= 3.11. The following runtime dependencies install with it:

- [Altair](https://altair-viz.github.io/) >= 6.0 - the charting layer
- [Polars](https://pola.rs/) >= 1.19 - the native `DataFrame` ([pandas](https://pandas.pydata.org/) input is accepted and converted)
- [NumPy](https://numpy.org/) >= 1.26 - numeric primitives
- [SciPy](https://scipy.org/) >= 1.11 - the statistics behind `ds.stats.comparisons()` / `ds.stats.correlation()`
- [vl-convert](https://github.com/vega/vl-convert) >= 1.9 - the SVG/PNG renderer behind `save()`

`pandas` and `duckdb` are optional and are only needed for `read(..., output="pandas"/"duckdb")`.

`dysonsphere` adds themes, marks, annotations, and export helpers to [Altair](https://altair-viz.github.io/). Its chart functions return native Altair chart objects.

## The library

Import the library through a single namespace, conventionally named `ds`:

- **`ds.theme()`** - register and apply a global theme. Charts built afterward the invocation inherit `ds.theme()`'s palettes and
  styling. See [Theming](/guides/theming/).
- **Marks** - `ds.mark_strip()`, `ds.mark_violin()` build composite plots. See [Marks](/guides/marks/).
- **Annotations** - `ds.rule()`, `ds.text()`, `ds.shade()`, `ds.labels()` return
  layers that can be composed with `Chart` objects using `+`. See [Reference lines](/guides/reference-lines/),
  [Shading](/guides/shading/), and [Text & labels](/guides/text-labels/).
- **Statistics** - `ds.stats.comparisons()` and `ds.stats.correlation()` perform statistical inference and render significance tests and
  correlation fits. See [Comparisons](/guides/comparisons/) and
  [Correlation](/guides/correlation/).
- **`ds.save()`** - write figures and their metadata to several possible fo rmats. **`ds.metadata.read()`** reads `Chart` metadata and, for JSON exports, captured data. **`ds.load()`** rebuilds a chart from a JSON export. See [Saving & reading](/guides/saving/).

## Saving

```python
ds.save(chart, "figure")   # writes figure.svg + figure.json by default
```

`save()` writes provenance, the resolved theme, and any statistic analysis to the export.

## Try it live

Every example has an **Open in studio** link. [Chart Studio](/studio/) runs the library in the browser through WebAssembly. Edit the code or upload data and use the chart controls.
