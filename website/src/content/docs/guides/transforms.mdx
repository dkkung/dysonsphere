title: Transforms
description: Offset transforms (jitter, beeswarm, quasirandom) that feed Altair's xOffset encoding.

import Example from '../../../components/Example.astro';

These standalone transforms add an offset column to a DataFrame for use with Altair's `xOffset`
encoding, including on custom marks. (`mark_strip()` uses them internally.)

`ds.transforms.jitter` adds Gaussian x-noise to reduce overplotting. Its default seed makes the
offsets reproducible. Jitter can separate overlapping points, such as raw points over a boxplot.

<Example name="jitter" alt="Jittered scatter using ds.transforms.jitter" />

`ds.transforms.beeswarm` packs points without overlap through exact collision avoidance. Tightly
packed rows can look lopsided: an even-count row places a point on the tick, and lone points shift
to one side.

<Example name="beeswarm" alt="Beeswarm scatter using ds.transforms.beeswarm" />

`ds.transforms.quasirandom` distributes points by local density using a deterministic van der
Corput sequence weighted by a kernel density estimate. This produces a symmetric, violin-shaped
swarm. It suits large or heavily tied groups but allows some overlap.

<Example name="quasirandom" alt="Quasirandom scatter using ds.transforms.quasirandom" />
