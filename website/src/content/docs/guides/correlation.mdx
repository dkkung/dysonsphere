[`ds.stats.correlation()`](/reference/stats/#correlation) adds a coefficient and optional p-value
to a scatterplot. Pearson correlation also adds an OLS fit line. Compose the result with `+`.

Each call builds a structured report that `save()` embeds in the export metadata. `report=True`
prints the report, and `saveReport=True` writes it to a file. By default, the readout shows
`r = …`; rank methods show only their coefficient.

<Example name="correlation" alt="Horsepower versus miles per gallon with an OLS fit line" />

For Pearson, `ci=True` draws a shaded band around the OLS fit; pass a level such as `ci=0.99`.

Choose what the band represents with `interval=`:

- `"confidence"` shows uncertainty in the mean response represented by the fit line.
- `"prediction"` gives a wider interval for a single new observation.

The band is drawn under the line and styled with `ciColor` and `ciOpacity`:

<Example name="correlation_ci" alt="OLS fit line with a shaded 95% confidence band" />

Readout components can be selected separately: `coefficient="both"` shows r and r²,
`includePvalue=True` adds P, and, for Pearson, `includeEquation=True` adds the fit line's equation.
`verbose=True` turns on all three. Longer readouts may need a wider chart; adjust `theme(width=…)`:

<Example name="correlation_both" alt="Scatter with an r, r-squared, and p-value readout" />

Rank correlations (`method="spearman"` / `"kendall"`) report a coefficient (ρ or τ); the p-value
is optional. They do not fit a straight-line model, so no fit line is drawn:

<Example name="correlation_spearman" alt="Weight versus miles per gallon, Spearman coefficient" />

## Per-series correlation

Pass `groupBy` to compute a correlation for each group. Pearson groups get a fit line by default
and can include an interval band. Readouts stack in the corner, one per series. The lines and
readout swatches use `groupBy` for color; color the scatter by the same field to match. This is a
color lookup, so no sort parameter is needed.

A custom `label=` value follows each group name. `lineStyle` overrides the curated line options in
single and grouped modes. `ciColor` sets the band fill; otherwise, it follows the effective line
color. `ci` syntax is still validated for rank methods, even though they draw no line or band.
