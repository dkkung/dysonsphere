`ds.theme()` registers a global Altair theme. Charts built afterwards inherit its palettes and
styling. Call it once to apply the theme to all further `Chart` objects. Calling it again re-applies the theme
to all charts that follow the theme call.

These two `Chart` objects also use `transparent=False`, so each renders its own contrasting `chartFill` background
(white by default, black in darkmode).

Ordinarily dysonsphere draws transparent backgrounds for all charts, letting the page or slide provide the background.
Every chart on on this website renders with `ds.them(darkmode=True)` when the theme preference of
the page is set to dark.

## Palettes

Pass `palette=` to set the default categorical color scheme. Hex codes for all palettes can be accessed
through `ds.palettes.colors` (or browse them all in the [Palettes](/guides/palettes/) gallery):

<Example name="bar" alt="Bar chart of mean barley yield by variety, blues palette" />

### Per-type palettes

`palette` sets the master scheme for every range i.e., data types (nominal, ordinal, categorical, diverging, and ramps).

To recolor just one channel, use the regular per-type
keys: `categoryPalette`, `divergingPalette`, `heatmapPalette`, `ordinalPalette`, and `rampPalette`, which each have matching
darkmode-specific overrides e.g., `categoryPaletteDarkmode` or `divergingPaletteDarkmode`.

The built-in light/dark defaults are `cat1`/`cat2` for categorical data, `div1`/`div2` for divergent data, `viridis` in both
modes for sequential data (heatmap and ramp), and `greys` in both modes for ordinal data.

<Example name="heatmap_palette" alt="2D histogram heatmap with the cosmos palette" />

## Style presets

Named presets that override several `ds.theme()` parameters are selected with `style=`.

There are two built-in presets:
- `"small"` is the default with a compact 70 x 70 px chart dimension and a 5 pt font size.
- `"notebook"` carries large-scale features for viewing in IDEs (900 x 900 px, 18 pt type, dark, transparent).

```python
ds.theme(style="small")              # compact figure
ds.theme(style="notebook")           # explore at screen scale
ds.theme()                           # back to publication defaults
```

A `dysonsphere.toml` config file can customise the existing presets or allow you to add your own named styles.

For example,
`ds.theme(style="poster")` picks up a custom `[poster]` section from your config. See the
[configuration guide](/guides/configuration/) for the full file format, search paths, and merge
order.

Use `ds.create_config()` to create the default `dysonsphere.toml` in either the current working directory or – with `persist=True`
– in your user configuration directory e.g., $XDG_CONFIG_HOME/dysonsphere/.

## Frame and grid

`closed=True` draws a full frame around the plot (using all four spines). Open and closed plots inset
the data from their axes or frame (`viewPadding`, on by default) so marks with values on domain edges don't
overlap with the border. The default inset is 5% of the smaller dimension e.g., 5px on the default 100x100 chart.

Pass a pixel value for a specific inset, or `viewPadding=False` for a flush frame. On an
auto-domained scale Vega-Lite rounds the request up to the next nice tick step; it lands
exactly where the domain is explicit:

<Example name="closed_frame" alt="Scatter plot with a closed frame" />

`grid=True` adds grid lines - solid by default; `gridStrokeDash=True` dashes them using the shared
`strokeDash` pattern:

<Example name="grid_lines" alt="Line chart with grid lines" />

## Rounded marks

`cornerRadius=True` rounds bar tips (and rects and arcs) by a size derived from the chart
dimensions. Pass a float for explicit rounding in pixels.

## Other settings

The theme exposes dozens of parameters - `axisOffset`, `tickSize`, `tickDirection`, `fontSize`,
`markSize`, `markStrokeWidth`, `barPadding`, `sigFigs`,
and the axis-element toggles (`xAxis`, `xTicks`, `xLabels`, and their `y` counterparts).

The [configuration guide's key reference](/guides/configuration/#key-reference) documents every parameter
with their defaults.
