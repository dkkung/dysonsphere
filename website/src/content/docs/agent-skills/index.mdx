The bundle contains the `dysonsphere` skill and three references. The [skill overview](dysonsphere/) describes the workflow; the reference pages cover plotting, statistics, and exports.

## Install

The bundle is distributed in this repository under `skills/dysonsphere/`. From the analysis project's
directory, install it with the [skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills add "/path/to/dysonsphere/skills/dysonsphere" --skill dysonsphere \
  --agent claude-code codex opencode --copy
```

Use the path to a checkout containing `skills/dysonsphere/`. The `--agent` option can select Claude
Code, Codex, and OpenCode; `--copy` copies the skill files into the selected locations.

Manual installation copies the `skills/dysonsphere/` directory, including `references/`, to
the selected agent's destination:

| Agent | Project destination |
| --- | --- |
| Claude Code | `.claude/skills/dysonsphere/` |
| Codex | `.agents/skills/dysonsphere/` |
| OpenCode | `.opencode/skills/dysonsphere/` |

## Invoke the skill

After installation, restart the harness if the skill is not detected. Invoke it as follows:

| Harness | Invocation |
| --- | --- |
| Claude Code | `/dysonsphere` |
| Codex | `$dysonsphere` |
| OpenCode | Ask OpenCode to load `dysonsphere`. |

Give the agent the data, analytical context, and figure task. For example:

```text
Use the dysonsphere skill to make a figure from data/results.csv. Preserve the observations and
analytical meaning, ask about unclear statistical comparisons, render with ds.save(), and report
the source, export paths, assumptions, and checks.
```

The bundle also includes [behavioral evaluation instructions](https://github.com/dkkung/dysonsphere/blob/main/skills/EVALUATION.md)
for comparing runs with and without the skill.
