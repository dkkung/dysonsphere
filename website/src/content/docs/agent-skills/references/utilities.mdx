Use this reference for result tables, condition and sample-size rows, or custom point offsets. It
covers `ds.mark_table()`, `ds.add_multilabel()`, and the `ds.transforms` dataframe helpers.

The standalone examples use synthetic data and save using Dysonsphere's built-in formats. Keep
tables and annotation rows aligned with the plotted categories and data subset; these helpers do not
establish a statistical comparison.
