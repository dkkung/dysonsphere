Use this reference before adding or changing inferential results. It describes chart annotations, not
a general numerical-analysis API.

It covers:

- establishing observational units, grouping, pairing, comparisons, and the multiple-testing family;
- pairwise and omnibus `ds.stats.comparisons()` modes, supported test choices, category order, and
  supplied p-values;
- `ds.stats.correlation()` methods, fit lines, confidence or prediction bands, and grouped fits;
- statistical records selected during saving, readable reports, and inspection through
  `ds.metadata.read()`.

Plan the analysis before applying the examples. The reference explains how to compare the stored
method, groups, counts, and correction with the intended analysis.
