**`dysonsphere-biology`** adds molecular-biology charts through the public core and `ext` APIs. Its charts use the active theme and work with `ds.save()` and `ds.metadata.read()`.

```sh
pip install dysonsphere-biology
```

Once installed, its charts resolve lazily under `ds.biology`:

```python
import dysonsphere as ds

ds.biology.volcano(df, labels="gene", subset=8)
```

## Volcano plot

`volcano()` draws log2 fold change against −log₁₀ p, classifies each point as gained / lost /
non-differential by the fold-change and p-value thresholds, colors it with the diverging
active theme's diverging range, keeps a separate darkmode-aware neutral grey, and layers on optional threshold guides and
gene labels:

<Example name="volcano" alt="Volcano plot of differential expression with labeled top genes" />

Gene labels use [`ds.labels`](/guides/text-labels/#point-labels). The placement is deterministic and connector-linked. The point ranking is domain-specific:
`subset=8` selects the 8 most significant genes by the combined score `|log2fc| × −log10(p)`.

### Key parameters

| Parameter | Default | What it does |
| --- | --- | --- |
| `log2fc` / `pvalue` | `"log2fc"` / `"pvalue"` | Effect-size and p-value column names |
| `labels` | `None` | Gene-name column (required when `subset` is set) |
| `fcThreshold` | `1.0` | `|log2fc|` significance cutoff; vertical guides at ±this |
| `pThreshold` | `0.05` | P-value cutoff; horizontal guide at −log₁₀ of it |
| `subset` | `None` | `int` (top-N by score), `"significant"` (all hits), or `list[str]` (named genes) |
| `thresholdLines` | `True` | Draw the fold-change / p-value guide lines |
| `palette` | theme diverging range | Registered name, low-to-high color list, or `(gained, lost)` tuple |
| `nonDifferentialColor` | theme grey | Non-differential point color (darkmode-aware) |
| `legend` | `True` | Show the significance color legend |

See the full signature and every parameter in the
[`dysonsphere_biology.volcano` reference](/extensions/volcano/).

:::note
Gained/lost colors inherit the theme's diverging scale natively; the neutral grey resolves at call time, so for a
correct light/dark export wrap the call in a `ds.save()` callable:

```python
ds.save(lambda: ds.biology.volcano(df, labels="gene", subset=8), "volcano")
```
:::
